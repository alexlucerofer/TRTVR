Verificar uma vaga

Cole o texto de um anúncio de emprego ou envie a imagem (panfleto, print de post). O ELO mostra sinais de recrutamento enganoso, tráfico de pessoas e trabalho escravo, com o trecho e o fundamento de cada alerta. O resultado aponta o que verificar; ele não afirma que houve crime.

Arraste, cole (Ctrl+V) ou clique para escolher uma imagem (até 5 MB)
A imagem não é guardada, só o resumo do resultado. API com documentação em /docs. Em caso de suspeita: Disque 100, Ligue 180, Polícia Federal, ou o Portal Consular se você estiver no exterior.
